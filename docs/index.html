What this shows

Reference-vector plane. The inner circle is the linear limit (m = 1). The green disk is the current operating radius m. Red wedges centred on the six active-vector directions are the blind zones where one active-vector dwell collapses below t_req, so single-shunt reconstruction fails without PWM shaping or estimation.

α_blind = arcsin( 2·t_req / (m·T_sw) )
