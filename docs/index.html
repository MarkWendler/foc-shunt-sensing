Single-Shunt Current Sensing — ADC & Modulation-Index Calculator

Interactive companion to “Acquisition-Time Limited Modulation in Single-Shunt Current Reconstruction for PMSM FOC”. The usable modulation index is set by the analog acquisition budget t_req = t_acq + t_blank + t_margin and the PWM period T_sw = 1/f_sw, not by ADC throughput.
